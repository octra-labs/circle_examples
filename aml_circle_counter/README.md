# AML Circle Counter

This contract is the current AML `octb` Circle counter example.

Prepared by Denis CMIX for the Octra network.

Use, modify, adapt, and redistribute this example as you see fit. No additional
restrictions are imposed by the example author.

Files:

* `main.aml` - AML contract source
* `circle.json` - Circle manifest
* `site/` - sealed browser demo assets

Logical methods:

* `get_counter`
* `get_label`
* `inc`

The demo site exercises:

* wallet context
* program info fallback for sealed circles
* counter reads
* counter increment writes
